### 2.6 Backup and restore (all Proposed)

1. Keep backup files read-only during normal operation (attrib +R on Windows / chmod 444) to prevent accidental edits. Test one restore before the first trial.

2. Copy each backup to a second drive (external USB) at End shift, because a backup on the same disk does not survive a disk failure. When a session is deleted under 2.8, execute the documented deletion workflow across the live database, local backups and USB backups (see 2.8). Proposed.
