## 11. Frozen Base Station Pin Map & Starter Implementation Contracts (Rev 3.2)

To eliminate hardware bring-up ambiguity between the Wearable Node (Technical Summary §3 Jacket Pin Map & §4 Status Bits) and the Radio Base Station, the Base ESP32-WROOM-32 (38-pin DevKit) + SX1276/XL1276 pin allocation and canonical SQLite Migration 0001 DDL are frozen below.

| Base Function | ESP32 GPIO | Electrical & Bring-Up Requirement |
|---|---|---|
| LoRa SPI SCK / MISO / MOSI | 18 / 19 / 23 | XL1276 / SX1276 SPI bus (3.3 V logic). |
| LoRa NSS / RST / DIO0 | 5 / 14 / 26 | 10 kOhm pull-up to 3.3 V on NSS (GPIO5 strapping pin); DIO0 = RxDone/TxDone IRQ. |
| Optional RF RXEN / TXEN | 16 / 17 | Only if module exposes external RF switch pins; fit 10 kOhm pull-downs on both. |
| Last-Resort OLED (128x64) | 21 (SDA) / 22 (SCL) | SSD1306 I2C at 0x3C (400 kHz); 4.7 kOhm pull-ups to 3.3 V. |
| Base Buzzer | 25 | Transistor/MOSFET driver via 1 kOhm resistor + flyback diode. |
| Status LEDs (Red / Amber / Green) | 27 / 32 / 33 | Active-HIGH via 330 Ohm series resistors to GND (safe at boot). |
| Base ACK Button | 4 | Input with external 10 kOhm pull-up to 3.3 V, 1 kOhm series, 100 nF to GND. |
| Base Battery Sense | 35 | Input-only ADC1_CH7 (100k/33k divider if 18650 boost pack; 5 V rail sense if sealed bank). |
| USB Auto-Reset Isolation | EN / IO0 | Cut/jumper DTR/RTS-to-EN transistor trace after flashing; preserve stock EN POR capacitor. |
