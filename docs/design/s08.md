### 8.1 Requirement traceability

Add requirements/requirements.yaml with one REQ-<area>-<nnn> ID for each Spec, Proposed and Decided statement that a test covers, with its status. Test names and docstrings include the REQ ID, and CI fails if an ID in a test is missing from the file, or a Spec item has no test. Section 7 (hazards H1 to H22) maps to REQ IDs rather than to prose.
