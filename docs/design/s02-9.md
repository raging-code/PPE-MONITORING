### 2.9 Tests that cover the database

| Test | What it proves |
|---|---|
| D1 | Decoded columns match the frame table; bad-length, bad-CRC and bad-MAC frames are stored as diagnostics; host and base MAC results agree and any disagreement is logged Rev 3.36: an OK frame whose node_id is not in roster (for example node 0 or node 2 when only node 1 is seeded) aborts at insert (trg_frames_roster), while BAD_LEN, BAD_CRC and BAD_MAC frames with any claimed node_id are still stored; the test seeds the roster first (seed-roster). |
| D8 | Resolve is refused without a reason and logs user and time; CSV export holds the full log; a missing or invalid token is rejected (logging the rejection is Proposed) |
| Soak test | Queue depth, overflow counter stays zero, database size, WAL checkpoints do not stall the writer |
| Migration test | Fresh database and upgrade from the previous version give the same schema; one backup is restored (Proposed); EXPLAIN QUERY PLAN of the GET /api/events query shows no scan of the frames table (Rev 3.41) |
| Fault and recovery (D8, soak) | Forced queue overflow, write error and low disk show LOGGING FAULT while alerts still show; a bad-frame flood leaves verified frames stored, with at most 20 bad frames per minute kept; a session older than 30 min is closed ABANDONED; a restart shows open alerts first, replays a 24 h database in 3 s or less and logs HOST_GAP |
| Recovery & ordering (checkpoints dormant, 2.10) | A missing or corrupt checkpoint is moot because none is written (2.10): the Tier 1 recovery path (open alerts and episodes plus the last 30 minutes of frames) always runs; a changed constants_hash or settings_hash closes the open session as ABANDONED (SESSION_ABANDONED detail config_hash_changed) and opens a new one that logs CONFIG_CHANGED, and open alerts and episodes survive it (Rev 3.41); event_seq remains strictly increasing across frames, alerts, audit_events, system_events and advisory_summaries after host restart and across End shift, where the new session continues the counter without reuse (Proposed) [Rev 3.27: Tier 1 exercises the fallback path only] |
