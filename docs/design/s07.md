## 7. Hazard to software traceability

The summary's Appendix C lists ten hazards, H1 to H10, and is extended as hazards are found, so add a row when it is. H11 to H22 are Proposed dashboard and host hazards to add to Appendix C. The D-tests are the summary's own. The mapping to host elements and stored columns is Proposed. For most hazards the mitigation is in firmware or hardware, and the host and dashboard show and log the result.

| Hazard | Host and dashboard element | What the database keeps | D-test |
|---|---|---|---|
| H1 Silent node power loss | Link-state tracker: signal lost at 15 s, link lost at 15 s after an adverse frame or 60 s regardless, same rule as the base panel. Battery warning at 10% or less from bat. | alerts (signal lost, link lost); frames.bat, rx_ts, frames_lost | D8, D9 (silence run), D2, D11 |
| H2 Conscious-but-trapped wearer | Shows MAYDAY (status4 bit 4 with mandown) and opens a MAYDAY episode. Gesture and resend are firmware. The host cannot trigger or clear it. | frames.status4; alerts (MAYDAY); episodes kind MAYDAY | D2, D9, D8 |
| H3 False "mated" wrist sense | Shows "wrist disconnected" (quiet) apart from "wrist lost" (WARNING). Sense-loop mitigation is hardware. | frames.status4, flags; alerts (wrist connector open or close) | D10 |
| H4 Stale SCBA-ON declaration | Always shows SCBA ON or OFF and the SCBA expired state. The confirmation clock runs on the node. SCBA correction is an audited action. | frames.id_mode, status3; alerts (SCBA expired); audit_events SCBA_CORRECTION | D4 |
| H5 CO sensor out of range | Shows the UNRELIABLE class grey. Out-of-range CO is never shown as zero and a raised level is held. Clamps are counted as co_over_range. | frames.co_x10, co_over_range, flags, status2; alerts (sensor fault) | D6, D5 |
| H6 Lost man-down latch | Shows the restored latch and NODE REBOOTED WHILE MAN-DOWN. The episode stays open across the reboot. The latch itself is node NVS. | frames.status3, status4, seq_class; episodes | D2 |
| H7 False ACK | ACK rule is node and base. The host counts bad frames and shows "frames rejected (authentication): check key". A forged alert shows as UNAUTHENTICATED ALERT. | base_health (rx_bad_mac, rx_bad_crc, rx_bad_len); frames.verify; alerts authenticated = 0 | D1, D9 |
| H8 Wrist-cable or sensor-head short | The host only sees the result: CO, IMU or temperature fault flags, and "shadow off: IMU fault". Jacket CANCEL does not depend on the wrist. | frames.status2, flags; alerts (sensor fault) | D10, D5 |
| H9 Battery thermal event | Shows battery percent and low flags only. Thermal cutoff is hardware, and its trip looks like H1 to the host. | frames.bat, status2 | D11 |
| H10 Single-host failure | Liveness timestamps on serial-reader, processing and tick tasks; stall over 3 s restarts the process; supervisor back within 5 s; RECOVERING replay; 1 Hz tick; NO LIVE DATA at 4 s from the Web Worker; DTR/RTS kept inactive. | system_events (HOST_START, LIVENESS_RESTART, RECOVERING_*); sessions (resume) | D8, D9 |
| H11 Missed or silently acknowledged alert | Tray that pushes the screen down, chips, sound until Acknowledge. An acknowledged man-down or MAYDAY has no reminder tone (decided), so its chip pulses at 2 min (unresolved_pulse_s = 120) and shows UNRESOLVED at 5 min (unresolved_label_s = 300). End shift warns on unresolved episodes. | alerts.acknowledged_ts and acknowledged_by; episodes; audit_events ACK, RESOLVE | D8 |
| H12 Audio muted or suspended | Siren ON or OFF indicator, Test sound before Start monitoring, SIREN OFF banner with one-click re-enable, AUDIO FAULT banner from the host. Browser sound (the NO LIVE DATA siren only) runs on the audio clock, not page timers; one audio-owner tab. | audit_events START_MONITORING | D8 |
| H13 Acknowledge mistaken for Resolve | Separate buttons, Resolve needs a reason, Acknowledge never closes a safety alert (only an unauth_alert closes on Acknowledge, 14.1b). | audit_events ACK, RESOLVE (reason) | D8 |
| H14 3D view failure | Flat component grid fallback. Readings, alerts, sound and Resolve do not depend on the 3D view. | None (client only) | D8, with the .stl blocked |
| H15 Cross-site call to the local API | Origin and Host check, token never in a cookie, localhost bind. | audit_events ORIGIN_REJECTED | D8 |
| H16 End shift pressed during an incident | End shift is never blocked. The confirmation lists open items and needs END; the host opens a new session at once and carries alerts and episodes over; alarms and sound continue. | audit_events END_SHIFT (open-item list); sessions end_kind | D8 |
| H17 Unsilenceable NO LIVE DATA siren leads to a muted laptop | Silence 60 s that re-arms, on the page alone; the host chime and the AUDIO FAULT check catch a missing audio device (and, with the optional pycaw check, a mute left on). | audit_events DASHBOARD_OUTAGE | D8 |
| H18 False or hidden alerts after a host restart | HOST_GAP is not counted as node silence; nodes show unconfirmed until a fresh frame; open alerts show before the replay ends; the replay is bounded to open alerts and episodes plus the last 30 minutes of frames (no checkpoint in Tier 1, 2.10). | system_events HOST_GAP, RECOVERING_* | D8, soak |
| H19 Logging fails without notice | LOGGING FAULT banner; alerts broadcast from memory; bounded ordered writer queue; rate limit for bad frames; low-disk check; synchronous=FULL. | system_events LOGGING_FAULT, DISK_LOW, QUEUE_OVERFLOW | D1, D8, soak |
| H20 Login failure or a disabled token blinds the commander | Tokens do not expire in Tier 1 (4.1); a disabled operator is rejected on every request; no lockout. | audit_events LOGIN_REJECTED, ORIGIN_REJECTED | D8 |
| H21 Host machine sleeps, suspends or does not restart | Windows host checklist (lid-close, USB selective suspend, power plan, login start); supervisor respawn and crash-loop guard; the base panel shows LAPTOP OFFLINE after 5 s without a host tick. | system_events HOST_START, SERIAL_LOST, TICK_STALL | D8 |
| H22 Database corrupt or unreadable at start-up | Start-up failure policy: quarantine the file, restore a verified backup or start a fresh database, never resume; banner until acknowledged; secrets failure exits with a clear message. | system_events INTEGRITY_FAIL; audit_events DB_RESTORED | D8 |
