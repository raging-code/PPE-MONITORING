### 3.4 Alert rules and wording (Proposed)

Thresholds are the Spec values from the summary's deterministic alert table. The dashboard does not hard-code them: it shows the level and reasons sent by the host, and the generated constants file stays the single source. Pop-up text is short, with the alias first and the live value. Every state the summary defines has one row and one way of showing, so nothing is left without a decision. The table is generated from the alert catalog, a JSON file (code, type, class, level, text, sound, badge order) shared by the host, the dashboard and the completeness test, so this table, the alert_types lookup table and the test cannot drift. The code of each row is in square brackets.

| Alert (level) | Raised when (Spec) | Pop-up text | Sound | Shows as |

Chest movement >STILL_G for 5 s changes only the label to "movement detected", and 15 s of renewed stillness reverts the label back to "no response"; card, siren and level never reduce. | FF-01 MAN-DOWN: no response (the line names the cause: still, check-in unanswered, IMU degraded) | Siren | Card |

| HOST GAP (system) [host_gap] | The host was down: no frames between the stop and the end of RECOVERING | MONITORING GAP 7 s: responders were not monitored | One beep | Banner, kept until acknowledged (system_events only; never in alerts table) |

| Watchdog or outage recovery (notice) [watchdog_recovery] | Node reboots after watchdog/brown-out/unclean reset (status3 bit 4 restored) or recovers from uplink outage (evt_unsent cleared) | FF-01 WATCHDOG / OUTAGE RECOVERED | None | Badge and log only |

Siren: loud two-tone, repeats until Acknowledge. Beep: medium double beep, every 10 s until Acknowledge. Chime: one soft tone at about a quarter of the beep volume. In the browser only the NO LIVE DATA siren plays, generated with the Web Audio API (no sound file) at a fixed volume with no mute control on the page in Tier 1. The host alarm sounds use the WAV files of 3.12. Completeness rule: every row of the alert_types lookup table (2.3, 25 types) and every banner of alert_catalog.json (7 banners including audio_fault, 3.12) must have a row here, and a test fails if one does not (all Proposed). NO LIVE DATA is the only alarm that can be silenced without the host: a Silence 60 s button works on the page alone, shows a countdown and re-arms when it ends, and the outage is reported to the host as DASHBOARD_OUTAGE after the reconnect. Order of sounds is in 3.3.
