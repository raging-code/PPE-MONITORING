# ADR 0069: the laptop battery is read with ctypes (GetSystemPowerStatus), not psutil

Status: Proposed (decided in the design-review preparation of 2026-11-28; builds the battery decision recorded in ADR 0036; confirm at the next design review).

Design: Rev 3.45 stays frozen. No wire, endpoint, setting, migration or constants change; `host_bat_warn_pct` and the 60 s check interval are unchanged.

- **Problem (ADR 0036, open item 1).** `default_battery()` used `psutil` only if it was installed. `psutil` is not in `pyproject.toml` or the lock files, so on the operator laptop the battery was always unknown and the HOST BATTERY warning never fired, with nothing to say so.
- **Decision.** `default_battery()` in `io/health.py` calls `GetSystemPowerStatus` in kernel32 through `ctypes` and fills a `SYSTEM_POWER_STATUS` structure. The host is Windows-only (it plays alarms through `winsound`), so there is no new dependency in the lock files or the release folder.
- **Reading the bytes.** `battery_from_status(ac_line, battery_flag, percent)` is a pure function. ACLineStatus 0 is on battery, 1 is on mains, anything else is unknown. BatteryFlag 128 means no system battery. A percentage above 100 (255 is unknown) becomes `None`. Unknown, no battery, a failed call and any other platform all give `(False, None)`: unknown is never reported as "on battery", as before.
- **What does not change.** `HostHealth`, `host_power_str` and the alarm levels are untouched; only the reader behind `default_battery` changed. The conftest fixture that replaces `default_battery` for every test stays.
- **Tests.** `host/tests/test_battery_ctypes.py`: the byte mapping, the unknown and no-battery cases, the struct size (12 bytes), the non-Windows path, and one test that runs only on Windows and calls the real function. On Linux the Windows test is skipped.
- **Not covered.** A real battery run. To check it on the field laptop, unplug the charger and wait up to one minute: the dashboard should show the host-on-battery notice and the event log a HOST_BATTERY row.
