# ADR 0022: Resolve dialog, Sessions list and End shift summary (P22c-4)

Status: Proposed (decided in the P22c-4 session; confirm at the next design review).
Design: Rev 3.45 is frozen. Nothing in the frame, the migration, constants.json, alert_catalog.json, hotspots.json or ws.schema.json changes.

- **Resolve dialog (3.3):** replaces the inline form of P22-3 (`components/ResolveDialog.tsx`, `Modal.tsx`). It names the node and the episode ID, offers the three reasons of the host as radio buttons, and Confirm resolve stays disabled until one is chosen. It says that Resolve does not clear the jacket latch. A call the host did not answer keeps the dialog open with "The host did not answer. Try again."; any other answer closes it and the card shows the words of P22-3. Cancel and Escape close it with no call. A click on the dim area does nothing (Proposed), so a stray click can neither cancel nor confirm. The dialog is drawn in `document.body` below the red NO LIVE DATA screen.
- **Top strip (3.10):** a minimal strip above the mode bar with the session label (or "Session n") and two buttons, Sessions and End shift. It is hidden under the red NO LIVE DATA screen like the other bars. Chips of minimized alerts join it in P22d.
- **Sessions list (3.10):** `GET /api/sessions?limit=50`, shown as a table: date (Asia/Manila, 24-hour), length, mode, alert count, and a Notes column (label, the end kind, "n unresolved"). The open session shows "(running)". It sits in normal flow like the tray, scrolls inside itself at 40% of the window height and covers nothing (Proposed: a modal list would hide alert cards while the operator reads old sessions). Failure shows "The host did not answer. Try again." with a button.
- **End shift (3.7, 3.8):** a modal confirmation that lists every open alert (`cleared_ts` null), every open episode (not RESOLVED) and every latched node (`mandown` 1 in the snapshot), says that nothing is silenced or hidden, and enables End shift only when `END` is typed in capitals (spaces around it are ignored). It sends `{confirm_text:'END', session_id}` with the open session's id. It is never blocked: it works with nothing open, before Start monitoring and while the host recovers (the host then answers 409 RECOVERING, shown as "The host is recovering. Try again in n s." from `retry_after_s`). 409 STATE_CONFLICT shows "The shift was already ended from another screen." The dialog stays open on any refusal.
- **Summary (3.10):** after a 200 the dialog closes and a one-screen summary opens in normal flow above the live screen, which keeps running (the new session is already open). It shows duration, alerts raised, unresolved episodes, the highest level of every rostered responder ("No warning or danger" when the host lists none: it omits a node with no WARNING or DANGER alert), the backup result and a Download CSV button. There is no endpoint for one session, so the figures come from `GET /api/sessions?limit=10` by `closed_session_id`; if that fails the summary still shows the backup result and the CSV button, says "The figures could not be loaded." and offers Try again. The summary shows only in the tab that ended the shift (Proposed); other tabs see the new session through the `system` message.
- **Backup result (Proposed wording):** "Backup saved", or "Backup FAILED. The shift data is still on the host." in the danger text colour. The design asks only for "the backup result".
- **CSV (3.8):** authenticated `GET /api/export.csv?session_id=<closed id>`, then a blob, an object URL and a temporary link named `session-<id>.csv`; never a plain link. The host endpoint is still pending (P26), so until then the button answers "The CSV could not be downloaded. Try again."
- **End kind wording (Proposed):** CLEAN_SHUTDOWN reads "Host shut down cleanly", ABANDONED reads "Host stopped without ending the shift"; ENDED adds nothing. Mode words: LIVE, "TEST: simulator", REPLAY.
- **REST helper:** `api/actions.ts` now has one exported `request()` (GET or POST, one outcome); a 409 carries `code` and `retryAfterS` so End shift can tell RECOVERING from STATE_CONFLICT. Existing callers are unchanged.
- **Not done here:** Playwright rows (End shift in a real browser keeps sound and cards, a second tab pressing End shift changes nothing, CSV file arrives); the 40% tray limit and 1366x768 layout with every panel open are P22c-5.
