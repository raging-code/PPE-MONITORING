# ADR 0009: operator CLI commands (P19b-2)

Status: Proposed (decided in the P19b-2 session; confirm at the next design review).
Design: Rev 3.45 is frozen. Nothing in the frame, the migration or `constants.json` changes.

- **Commands:** `python -m ppe_host.cli create-operator --name N`, `rotate-token --operator-id N`, `disable-operator --operator-id N`, each with optional `--home` (default `PPE_HOME`, else the repository folder) and `--db` (default `db_path` of the settings). The functions sit in `cli.py`, the file the layout of 14.5 names for CLI actions; the security helpers they use are in `api/security.py` (ADR 0008).
- **Token:** shown once on standard output and never stored (only its HMAC) or logged. Errors go to standard error with exit code 1 and never contain a token.
- **Audit rows:** `OPERATOR_ADDED`, `TOKEN_ROTATED` and `OPERATOR_DISABLED` are written in the same transaction as the change, with `session_id` NULL, `event_seq` 0 and `operator_id` NULL, as 2.3 says for offline CLI actions. The affected operator goes in `reason` as `operator_id <n>` (proposal: the table has no other column for it). They are not in `v_full_log`, so they are read from `audit_events` (2.5). Event_seq 0 never moves `init_event_seq`.
- **Rules (proposals where 3.8 and 4 are silent):** a name is stripped and must be non-empty and unique; `create-operator` is the only command that may create the schema or `secrets.json` (it applies migration 0001 to an empty file as `seed-roster` does); `rotate-token` and `disable-operator` refuse a missing database, an unknown id and a missing `server_salt`; `rotate-token` refuses a disabled operator because there is no enable command; `disable-operator` on an already disabled operator is exit 0 with no second audit row. Rotating or disabling takes effect on the next request (`authenticate` reads the table each time); closing an open socket is P20.
- **Running host:** the commands write through a separate connection with a busy timeout, so they may run while the host is up. The design says to rotate "between shifts"; nothing stops a rotation during one, and the audit row then has no session.
- **Not built: `cli ack --node N`.** Design 8 ("Host sound files and CLI stop test") has it stop a man-down siren on the host sink with zero browser tabs open and write `ACK_ALERT`. That needs the running host (engine state and the audio thread), which exist only in P23 and P24, so it cannot be an offline database command. It moves to P24, with the host exposing a local control path; the P19b row of the guide is partly open until then.
